---
title: Dispatch Bridge
description: The Dispatcher bridge to Dispatch, and what uses it today.
---

The Dispatch bridge connects Authsome to [Dispatch](https://github.com/xraph/dispatch)'s job queue. Today only the `notification` plugin looks at it: when a dispatcher is configured, the plugin sends its notifications asynchronously. The core engine doesn't enqueue anything, so session cleanup and retention run in-process whether or not Dispatch is configured.

## Interface

The `bridge.Dispatcher` interface is defined in `github.com/xraph/authsome/bridge`:

```go
type Dispatcher interface {
    Enqueue(ctx context.Context, jobType string, payload []byte) error
    Schedule(ctx context.Context, jobType string, payload []byte, runAt time.Time) error
}
```

## Setup with the Dispatch adapter

```go
import (
    "github.com/xraph/authsome"
    "github.com/xraph/authsome/bridge/dispatchadapter"
    "github.com/xraph/dispatch"
    "github.com/xraph/dispatch/engine"
)

// Build the Dispatch engine (see Dispatch's docs for stores and workers).
d, err := dispatch.New(dispatch.WithStore(dispatchStore))
if err != nil {
    log.Fatal(err)
}
dispatchEng, err := engine.Build(d)
if err != nil {
    log.Fatal(err)
}

// Wrap in the Authsome adapter.
dispatchBridge := dispatchadapter.New(dispatchEng)

// Register with Authsome.
eng, err := authsome.NewEngine(
    // plus WithChronicle and WithWarden, which every engine needs (see Getting Started)
    authsome.WithStore(pgStore),
    authsome.WithDispatcher(dispatchBridge),
)
```

## What Authsome sends through it

| Caller | Behaviour with a dispatcher |
|--------|-----------------------------|
| `notification` plugin | Sends notifications asynchronously (the same as `Async: true` in its config) |

Nothing else calls `Enqueue` or `Schedule`. Your own plugins can reach the bridge through the plugin engine's `Dispatcher()` and enqueue jobs there; the adapter forwards the job name and payload to Dispatch.

## Standalone development stub

During development, use the built-in `NoopDispatcher` stub:

```go
import "github.com/xraph/authsome/bridge"

eng, err := authsome.NewEngine(
    // plus WithChronicle and WithWarden, which every engine needs (see Getting Started)
    authsome.WithStore(memory.New()),
    authsome.WithDispatcher(bridge.NewNoopDispatcher()),
)
```

<Callout type="info">
`NoopDispatcher` returns `ErrDispatchNotAvailable` from every call.
</Callout>
