---
title: Bridges
description: Optional integration adapters that connect Authsome to the broader Forgery ecosystem.
---

Bridges connect Authsome to other systems, mostly other Forgery libraries. Each bridge is a small Go interface in `github.com/xraph/authsome/bridge`. You implement it yourself, use an adapter package, or use a built-in stub during development.

Two bridges are required. `NewEngine` fails without Chronicle (`WithChronicle`) and without Warden (`WithWarden`). The others are optional: when one isn't configured, Authsome uses a no-op and skips that work, so no webhooks go out and no email is sent.

## The bridge pattern

Each bridge follows the same pattern:

1. An interface in `github.com/xraph/authsome/bridge`, a few methods at most.
2. An adapter package, `github.com/xraph/authsome/bridge/<name>adapter`, that wraps the real client.
3. A no-op stub in `bridge/stubs.go`, used when the bridge isn't configured.
4. A `With*` option on the engine.

```
bridge/
  chronicle.go, relay.go, herald.go, vault.go, dispatch.go, ledger.go,
  warden.go, keysmith.go, mailer.go, sms.go, metrics.go   interfaces
  stubs.go                                                no-op implementations
  memory_chronicle.go, memory_relay.go                    in-memory versions for tests
  chronicleadapter/   wraps a chronicle.Emitter
  relayadapter/       wraps *relay.Relay
  heraldadapter/      wraps *herald.Herald
  vaultadapter/       wraps Vault's secret, flag and config services
  dispatchadapter/    wraps *dispatch.Engine
  ledgeradapter/      wraps *ledger.Ledger
  wardenadapter/      wraps *warden.Engine
  keysmithadapter/    wraps *keysmith.Engine
  metricsadapter/     wraps forge.Metrics
  maileradapter/      Resend and SMTP
  smsadapter/         Twilio
```

## Available bridges

| Bridge | Option | Interface | What it does |
|--------|--------|-----------|-------------|
| Chronicle (required) | `WithChronicle` | `bridge.Chronicle` | Records auth events to an audit trail |
| Relay | `WithEventRelay` | `bridge.EventRelay` | Delivers webhook payloads to subscribers |
| Herald | `WithHerald` | `bridge.Herald` | Multi-channel notifications (email, SMS, push) |
| Vault | `WithVault` | `bridge.Vault` | Secrets management and feature flags |
| Dispatch | `WithDispatcher` | `bridge.Dispatcher` | Background job queue for async tasks |
| Ledger | `WithLedger` | `bridge.Ledger` | Billing metering and entitlement checks |
| Warden (required) | `WithWarden` (and optionally `WithAuthorizer`) | `*warden.Engine`, `bridge.Authorizer` | RBAC and policy evaluation |
| Keysmith | `WithKeysmith` / `WithKeyManager` | `bridge.KeyManager` | Centralized API key management |
| Mailer | `WithMailer` | `bridge.Mailer` | Transactional email delivery |
| SMS | `WithSMSSender` | `bridge.SMSSender` | SMS delivery for OTP and MFA codes |
| Metrics | `WithMetrics` | `bridge.MetricsCollector` | Observability metrics export |

## Registering bridges

Bridges are registered using the corresponding `With*` option when constructing the engine:

```go
import (
    "github.com/xraph/authsome"
    "github.com/xraph/authsome/bridge/chronicleadapter"
    "github.com/xraph/authsome/bridge/relayadapter"
    "github.com/xraph/authsome/bridge/maileradapter"
)

eng, err := authsome.NewEngine(
    authsome.WithStore(pgStore),
    authsome.WithWarden(wardenEngine),
    authsome.WithPlugin(password.New()),

    // Chronicle: audit all auth events. Takes a chronicle.Emitter.
    authsome.WithChronicle(chronicleadapter.New(chronicleEngine)),

    // Relay: deliver webhook events reliably.
    authsome.WithEventRelay(relayadapter.New(relayEngine)),

    // Mailer: send verification and reset emails.
    authsome.WithMailer(maileradapter.NewResendMailer(os.Getenv("RESEND_API_KEY"), "noreply@myapp.com")),
)
```

## Using the Forgery first-class bridge options

For Warden and Keysmith, `WithWarden` and `WithKeysmith` take the engine itself, so you don't import the adapter:

```go
import (
    "github.com/xraph/warden"
    "github.com/xraph/keysmith"
)

wardenEng, err := warden.NewEngine(warden.WithStore(wardenStore))
keysmithEng, err := keysmith.NewEngine(/* ... */)

eng, err := authsome.NewEngine(
    authsome.WithStore(pgStore),
    authsome.WithChronicle(chronicleBridge),
    // WithWarden accepts *warden.Engine directly.
    authsome.WithWarden(wardenEng),
    // WithKeysmith accepts *keysmith.Engine directly.
    authsome.WithKeysmith(keysmithEng),
)
```

Both wrap the engine in its adapter and also set the `bridge.Authorizer` or `bridge.KeyManager`.

## No-op stubs for development

For local work without the rest of the stack, use the in-memory and no-op versions. The no-op ones that log take a go-utils `log.Logger`:

```go
import (
    "github.com/xraph/go-utils/log"

    "github.com/xraph/authsome/bridge"
)

logger := log.NewDevelopmentLogger()

eng, err := authsome.NewEngine(
    authsome.WithStore(memory.New()),
    authsome.WithWarden(wardenEng),
    // Keep audit events in memory.
    authsome.WithChronicle(bridge.NewMemoryChronicle()),
    // Log webhook events and drop them.
    authsome.WithEventRelay(bridge.NewNoopRelay(logger)),
    // Log emails instead of sending them.
    authsome.WithMailer(bridge.NewNoopMailer(logger)),
)
```

## Custom bridge implementations

You can implement any bridge interface directly if you want to integrate with a system that does not have a Forgery adapter:

```go
// Custom Mailer using SendGrid.
type SendGridMailer struct {
    client *sendgrid.Client
    from   string
}

func (m *SendGridMailer) SendEmail(ctx context.Context, msg *bridge.EmailMessage) error {
    message := mail.NewSingleEmail(
        mail.NewEmail("", m.from),
        msg.Subject,
        mail.NewEmail("", msg.To[0]),
        msg.Text,
        msg.HTML,
    )
    _, err := m.client.SendWithContext(ctx, message)
    return err
}

// Register with the engine.
eng, err := authsome.NewEngine(
    // plus WithChronicle and WithWarden, which every engine needs (see Getting Started)
    authsome.WithStore(pgStore),
    authsome.WithMailer(&SendGridMailer{
        client: sendgrid.NewSendClient(os.Getenv("SENDGRID_API_KEY")),
        from:   "noreply@myapp.com",
    }),
)
```
