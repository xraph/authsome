Organizations group users inside an app. The `organization` plugin adds them, along with members, invitations and teams. Each organization belongs to an app and an environment.

## The Organization model

```go
import "github.com/xraph/authsome/organization"

type Organization struct {
    ID        id.OrgID         `json:"id"`     // aorg_ prefix
    AppID     id.AppID         `json:"app_id"`
    EnvID     id.EnvironmentID `json:"env_id"`
    Name      string           `json:"name"`
    Slug      string           `json:"slug"`
    Logo      string           `json:"logo,omitempty"`
    Metadata  Metadata         `json:"metadata,omitempty"` // map[string]string
    CreatedBy id.UserID        `json:"created_by"`
    CreatedAt time.Time        `json:"created_at"`
    UpdatedAt time.Time        `json:"updated_at"`
}
```

Slugs are unique within an app. Creating an organization with a slug that's taken returns `ErrSlugTaken` from the plugin package (409 over HTTP). `GET /v1/orgs/check-slug` tells you whether a slug is free.

## Setting up the plugin

```go
import (
    "time"

    "github.com/xraph/authsome"
    orgplugin "github.com/xraph/authsome/plugins/organization"
)

orgs := orgplugin.New(orgplugin.Config{
    InvitationTTL: 72 * time.Hour, // default 7 days; negative means invitations never expire
})

eng, err := authsome.NewEngine(
    // plus WithStore, WithChronicle and WithWarden (see Getting Started)
    authsome.WithPlugin(orgs),
)
```

`Config` has two fields: `InvitationTTL` and `PathPrefix`. Standalone, mount the plugin's routes the way [Getting Started](/docs/getting-started) does (the loop over `eng.Plugins().RouteProviders()`); the Forge extension mounts them for you.

## Go API

The operations are methods on the plugin. Keep the value you passed to `WithPlugin`, or look it up with `eng.Plugin("organization").(*orgplugin.Plugin)`.

```go
import (
    "github.com/xraph/authsome/id"
    "github.com/xraph/authsome/organization"
)

org := &organization.Organization{
    ID:        id.NewOrgID(),
    AppID:     appID,
    EnvID:     envID,
    Name:      "Acme Corporation",
    Slug:      "acme",
    CreatedBy: userID,
    Metadata:  organization.Metadata{"plan": "enterprise"},
}
if err := orgs.CreateOrganization(ctx, org); err != nil {
    return err
}
```

`CreateOrganization` adds `CreatedBy` as an `owner` member. You set the ID; the plugin doesn't generate one.

| Method | Description |
|--------|-------------|
| `CreateOrganization(ctx, *Organization)` | Create, and add the creator as owner |
| `GetOrganization(ctx, orgID)` | Get by ID |
| `UpdateOrganization(ctx, *Organization)` | Save changes |
| `DeleteOrganization(ctx, orgID)` | Delete |
| `ListUserOrganizations(ctx, userID)` | Organizations a user belongs to (`ListUserOrganizationsPage` pages) |
| `AdminListOrganizations(ctx, appID)` | Every organization in an app |
| `IsOrgSlugAvailable(ctx, appID, slug)` | Slug check |

Members, invitations and teams have their own pages: [Members](/docs/organizations/members), [Invitations](/docs/organizations/invitations) and [Teams](/docs/organizations/teams).

## HTTP API

The plugin registers these routes under `/v1` (under `/authsome/v1` with the Forge extension):

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/v1/orgs` | Create an organization (`name`, `slug`, optional `logo`, `app_id`) |
| `GET` | `/v1/orgs` | Organizations the signed-in user belongs to |
| `GET` | `/v1/orgs/check-slug` | Whether a slug is free |
| `GET` | `/v1/orgs/:orgId` | Get one |
| `PATCH` | `/v1/orgs/:orgId` | Update `name` or `logo` |
| `DELETE` | `/v1/orgs/:orgId` | Delete |

The member, invitation and team routes are listed on their pages. `POST /v1/me/switch-org` moves the current session to another organization the user belongs to.

## Events

Organization changes are recorded through the hook bus (and so to Chronicle) as `org.create`, `org.update`, `org.delete`, `org.member.add`, `org.member.remove`, `org.member.role_change`, `org.invitation.accept`, `org.invitation.decline` and the `org.team.*` actions. With a Relay bridge, the plugin also sends the webhook events `org.created`, `org.member.role_changed`, `org.invitation.accepted`, `org.invitation.declined` and `org.team.created`. See [Webhooks](/docs/security/webhooks).
