title: Teams

---

Teams are named groups inside an organization, such as Engineering or Support.

## The Team model

```go
import "github.com/xraph/authsome/organization"

type Team struct {
    ID        id.TeamID `json:"id"`     // atm_ prefix
    OrgID     id.OrgID  `json:"org_id"`
    Name      string    `json:"name"`
    Slug      string    `json:"slug"`
    CreatedAt time.Time `json:"created_at"`
    UpdatedAt time.Time `json:"updated_at"`
}
```

<Callout type="info">
A team is a name and a slug. The plugin has no team membership: no routes, no methods and no table link users to teams. If you need membership, keep it in your own tables keyed by the team ID.
</Callout>

## Go API

```go
team := &organization.Team{
    ID:    id.NewTeamID(),
    OrgID: orgID,
    Name:  "Engineering",
    Slug:  "engineering",
}
err := orgs.CreateTeam(ctx, team)

t, err := orgs.GetTeam(ctx, teamID)
err = orgs.UpdateTeam(ctx, t)
teams, err := orgs.ListTeams(ctx, orgID) // ListTeamsPage for paging
err = orgs.DeleteTeam(ctx, teamID)
```

## HTTP API

| Method | Path | Body | Needs |
