title: Members

A member links a user to an organization with one of three roles.

## The Member model

```go
import "github.com/xraph/authsome/organization"

type Member struct {
    ID        id.MemberID `json:"id"`     // amem_ prefix
    OrgID     id.OrgID    `json:"org_id"`
    UserID    id.UserID   `json:"user_id"`
    Role      MemberRole  `json:"role"`
    CreatedAt time.Time   `json:"created_at"`
    UpdatedAt time.Time   `json:"updated_at"`
}

const (
    RoleOwner  MemberRole = "owner"
    RoleAdmin  MemberRole = "admin"
    RoleMember MemberRole = "member"
)
```

The roles rank owner, then admin, then member. Over HTTP:

- Reading the organization, its members and its teams needs any membership.
- Adding and removing members, inviting, and creating, updating or deleting teams need `admin` or above.
- Changing a member's role and deleting the organization need `owner`.
- Nobody can grant a role above their own or remove a member who outranks them. Only an owner can remove an owner, and the last owner can't be removed.

These are organization roles, separate from the app's RBAC roles in Warden.

## Go API

On the plugin (see [Organizations Overview](/docs/organizations/overview) for getting it):

```go
err := orgs.AddMember(ctx, &organization.Member{
    ID:     id.NewMemberID(),
    OrgID:  orgID,
    UserID: userID,
    Role:   organization.RoleMember,
})

members, err := orgs.ListMembers(ctx, orgID) // ListMembersPage for paging

updated, err := orgs.UpdateMemberRole(ctx, memberID, organization.RoleAdmin)

err = orgs.RemoveMember(ctx, memberID)
```

The Go methods don't apply the HTTP ranking rules above; they're for code you trust.

## HTTP API

| Method | Path | Body | Needs |
|--------|------|------|-------|
| `GET` | `/v1/orgs/:orgId/members` | | member |
| `POST` | `/v1/orgs/:orgId/members` | `{"user_id": "ausr_...", "role": "member"}` | admin |
| `PATCH` | `/v1/orgs/:orgId/members/:memberId` | `{"role": "admin"}` | owner |
| `DELETE` | `/v1/orgs/:orgId/members/:memberId` | | admin |

`role` defaults to `member`.

## The active organization

A session can carry an active organization. `POST /v1/me/switch-org` changes it for the current session (the user has to be a member), and `middleware.OrgIDFrom(ctx)` reads it in your handlers.
