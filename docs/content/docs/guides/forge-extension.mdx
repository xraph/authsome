---
title: Forge Extension
description: Mount Authsome into a Forge application as an extension with bridge discovery and route registration.
---

The `github.com/xraph/authsome/extension` package registers Authsome as a [Forge](https://github.com/xraph/forge) extension. It reads `extensions.authsome` (or a top-level `authsome` key), builds a store from the container's `*grove.DB`, mounts the API under `/authsome`, runs the bootstrap and adds the auth middleware to your app.

## Installation

```bash
go get github.com/xraph/authsome@latest github.com/xraph/chronicle@latest \
  github.com/xraph/warden@latest github.com/xraph/grove/extension@latest
```

## Registering the extension

```go
import (
    "github.com/xraph/forge"
    grove "github.com/xraph/grove/extension"

    authsome "github.com/xraph/authsome/extension"
    "github.com/xraph/authsome/plugins/mfa"
    "github.com/xraph/authsome/plugins/password"
    chronicle "github.com/xraph/chronicle/extension"
    warden "github.com/xraph/warden/extension"
)

app := forge.NewApp(forge.AppConfig{
    Name: "acme-api",
    Extensions: []forge.Extension{
        grove.New(),     // extensions.grove: driver and dsn
        chronicle.New(), // audit trail, required by authsome
        warden.New(),    // authorization, required by authsome
        authsome.New(
            authsome.WithPlugins(
                password.New(),
                mfa.New(mfa.Config{Issuer: "Acme"}),
            ),
        ),
    },
})
```

Order matters. Authsome looks for `chronicle.Emitter` and `*warden.Engine` in the container during `Register` and refuses to start without them, so list Chronicle and Warden first. Grove has to come first too, because the store is built from its `*grove.DB`.

The engine also needs a token encryption key: set `AUTHSOME_TOKEN_ENCRYPTION_KEY` to 64 hex characters (or `AUTHSOME_TOKEN_ENCRYPTION_KEYS` as `kid:hex` pairs when you rotate), or pass an encryptor with `authsome.WithEngineOption(authsomecore.WithTokenEncryptor(enc))`, where `authsomecore` is the root `github.com/xraph/authsome` package.

To use a store you build yourself (in an app without the Grove extension, see [Grove database](#grove-database)):

```go
import (
    authsomecore "github.com/xraph/authsome"
    pgstore "github.com/xraph/authsome/store/postgres"
)

authExt := authsome.New(
    authsome.WithEngineOption(authsomecore.WithStore(pgstore.New(db))),
)
```

## What the extension does

| Lifecycle event | Behaviour |
|----------------|-----------|
| `Register` | Loads configuration, resolves Chronicle and Warden (required) and the optional bridges from DI, builds the store and engine, provides `*authsome.Engine`, mounts the routes |
| `Start` | Starts the engine: migrations (unless disabled), bootstrap, plugin `OnInit` |
| `Middlewares` | Returns the auth middleware, which Forge applies to every route |
| `Stop` | Calls `engine.Stop`, which emits `OnShutdown` to every plugin |

## Extension options

| Option | Default | Description |
|--------|---------|-------------|
| `WithConfig(cfg)` | `DefaultConfig()` | The whole config struct |
| `WithPlugin(p)`, `WithPlugins(ps...)` | none | Register plugins |
| `WithEngineOption(opt)`, `WithEngineOptions(opts...)` | none | Pass root `authsome.Option` values to the engine |
| `WithBasePath(path)` | `"/authsome"` | URL prefix for the routes (the API itself is under `<base_path>/v1`) |
| `WithDisableRoutes()` | off | Skip route registration |
| `WithDisableMigrate()` | off | Skip migrations on start |
| `WithGroveDatabase(name)` | the default `*grove.DB` | A named Grove database |
| `WithRequireConfig(b)` | `false` | Fail when there's no YAML config |
| `WithLogger(l)` | the app's logger | A go-utils `log.Logger` |
| `WithClientMode(portalURL)`, `WithServiceAPIKey(key)`, `WithServiceAppID(id)`, `WithClientAutoRefresh(on, threshold)` | off | Client mode, below |

## Bridges

Chronicle and Warden are required. Everything else is optional: when the matching service is in the container, the extension wires it in as a bridge, and otherwise it uses a no-op.

| Bridge | Discovered from | Purpose |
|--------|----------------|---------|
| Chronicle (required) | `chronicle.Emitter` | Audit trail |
| Warden (required) | `*warden.Engine` | RBAC authorization |
| Keysmith | `*keysmith.Engine` | API key management |
| Relay | `*relay.Relay` | Webhook delivery |
| Herald | `*herald.Herald` | Notifications |
| Dispatch | `*dispatch.Engine` | Background jobs |
| Ledger | `*ledger.Ledger` | Billing and metering |
| Grove DB | `*grove.DB` | The store (PostgreSQL, SQLite or MongoDB) |

## YAML configuration

The extension reads `extensions.authsome`, then a top-level `authsome` key:

```yaml
extensions:
  authsome:
    base_path: /authsome
    grove_database: primary          # optional; the default *grove.DB otherwise
    session:
      token_ttl: 1h
      refresh_token_ttl: 720h
      max_active_sessions: 5         # 0 means unlimited
      rotate_refresh_token: true
    password:
      min_length: 12
      require_uppercase: true
      require_lowercase: true
      require_digit: true
      algorithm: argon2id            # bcrypt by default; old hashes are rehashed on sign-in
      check_breached: true
    rate_limit:
      enabled: true                  # on unless explicitly false
      signin_limit: 5
      signup_limit: 3
      window_seconds: 60
    lockout:
      enabled: true                  # on unless explicitly false
      max_attempts: 5
      lockout_duration_seconds: 900
      reset_after_seconds: 3600
    mailer:
      provider: resend               # resend or smtp; nothing is sent otherwise
      resend:
        api_key: "${RESEND_API_KEY}"
        from: noreply@example.com
    bootstrap:
      app_name: Acme
      initial_owners: [founder@example.com]
```

The `Config` struct in `extension/config.go` also covers `retention`, `csrf`, `webhooks`, per-app session settings under `apps`, bootstrap environments and `warden_dir` for your own role files, `dashboard`, and the client-mode keys.

### Merge behaviour

YAML is merged with your programmatic options. Boolean flags you set in code (`DisableRoutes`, `DisableMigrate`, `Debug`) win when they're `true`. For other fields YAML takes precedence, then your options, then the defaults.

## Accessing the engine

After Forge has called `Register`, `authExt.Engine()` returns the engine. It's also in the container:

```go
import (
    "github.com/xraph/vessel"

    authsomecore "github.com/xraph/authsome"
)

eng, err := vessel.Inject[*authsomecore.Engine](app.Container())
```

## Adding plugins

```go
import (
    "github.com/xraph/authsome/plugins/magiclink"
    "github.com/xraph/authsome/plugins/mfa"
    "github.com/xraph/authsome/plugins/passkey"
    "github.com/xraph/authsome/plugins/password"
    "github.com/xraph/authsome/plugins/phone"
    "github.com/xraph/authsome/plugins/social"
)

authExt := authsome.New(
    authsome.WithPlugins(
        password.New(),
        social.New(social.Config{
            // Callbacks default to {Domain}/v1/social/{provider}/callback.
            Domain: "https://app.example.com/authsome",
            Providers: []social.Provider{
                social.NewGoogleProvider(social.ProviderConfig{
                    ClientID:     os.Getenv("GOOGLE_CLIENT_ID"),
                    ClientSecret: os.Getenv("GOOGLE_CLIENT_SECRET"),
                }),
                social.NewGitHubProvider(social.ProviderConfig{
                    ClientID:     os.Getenv("GITHUB_CLIENT_ID"),
                    ClientSecret: os.Getenv("GITHUB_CLIENT_SECRET"),
                }),
            },
        }),
        mfa.New(mfa.Config{Issuer: "Acme"}),
        passkey.New(passkey.Config{
            RPDisplayName: "My App",
            RPID:          "example.com",
            RPOrigins:     []string{"https://example.com"},
        }),
        magiclink.New(),
        phone.New(),
    ),
)
```

## Auth middleware

The extension's `Middlewares()` returns the auth middleware, and Forge applies it to every route. It:

1. Reads the `Authorization: Bearer <token>` header (or the session cookie)
2. Resolves the session (an opaque lookup, or JWT validation for apps on the JWT format)
3. Falls back to the strategy registry (API keys and so on) when session resolution fails
4. Puts the user and session on the request context

Read them in your handlers with the `middleware` package:

```go
import "github.com/xraph/authsome/middleware"

func handler(ctx forge.Context) error {
    user, ok := middleware.UserFrom(ctx.Context())
    if !ok {
        return forge.Unauthorized("sign in first")
    }
    orgID, _ := middleware.OrgIDFrom(ctx.Context())
    // ...
}
```

The middleware doesn't require authentication on its own. Routes that need a user check for one, as above.

## Grove database

By default the extension uses the default `*grove.DB` in the container. Name a different one with `WithGroveDatabase("authsome")` or `grove_database: authsome`. The store backend is picked from the Grove driver: PostgreSQL, SQLite or MongoDB.

A store passed with `WithEngineOption(authsomecore.WithStore(s))` is applied before the Grove one, so whenever a `*grove.DB` is in the container the Grove store wins. Pass your own store only in apps that don't register Grove.

## Client mode

A service that should trust an Authsome deployment elsewhere, rather than run its own, uses client mode:

```go
authExt := authsome.New(
    authsome.WithClientMode("https://auth.example.com/authsome"),
    authsome.WithServiceAPIKey(os.Getenv("AUTHSOME_SERVICE_KEY")),
    authsome.WithServiceAppID("aapp_..."),
)
```

In client mode the extension validates incoming tokens against the remote deployment instead of building a local engine.

## Dashboard integration

When the Forge dashboard extension is present, Authsome registers as its authentication provider and contributes its pages through the dashboard contract.
