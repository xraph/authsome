Authsome is a Go library that delivers complete authentication and identity management for production applications. It covers password sign-in, enterprise SSO, multi-factor authentication, passkeys, social login, organizations, RBAC, webhook delivery and dynamic sign-up forms, all behind one `Engine` type you embed in your own application.

Authsome is a library, not a service. You bring the database, the HTTP server and the process lifecycle; Authsome brings the authentication plumbing. It does need two other xraph libraries at runtime: [Chronicle](https://github.com/xraph/chronicle) for the audit trail and [Warden](https://github.com/xraph/warden) for authorization.

## What it does

| Capability | Details |
|------------|---------|
| 27 plugins | Sign-in methods (`password`, `magiclink`, `social`, `sso`, `passkey`, `mfa`, `phone`), `oauth2provider`, `organization`, `apikey`, `scim`, `consent`, `retention`, risk signals (`riskengine`, `geoip`, `impossibletravel` and more) and others. See [Plugins](/docs/plugins/overview) |
| 4 store backends | `memory` (testing), `postgres`, `sqlite`, `mongo` |
| UI components | `@authsome/ui-react`, `-vue` and `-nextjs` on top of `@authsome/ui-core` and `@authsome/ui-components`, plus the `@authsome/client` SDK |
| Webhook events | Sign-in, user, organization, MFA and session events, delivered through the Relay bridge |
| TypeIDs | Prefixed, sortable IDs such as `ausr_` (users), `ases_` (sessions), `aapp_` (apps) and `aenv_` (environments) |
| Token formats | Opaque (64-char hex, default) or JWT with OIDC claims, configurable per app |
| Session management | Token + refresh token pairs, rotation, IP/device binding, max active sessions |
| Environments | Isolated production, staging, and development environments per app |
| RBAC | Roles, permissions, role hierarchy with native Warden integration |
| Dynamic forms | Field-level validation and metadata capture on sign-up and other flows |
| Bridges | Chronicle (audit, required), Warden (authorization, required), Relay (webhooks), Mailer, SMS, Herald (notifications), Keysmith (API keys), Vault (secrets), Dispatch (jobs), Ledger (billing), Metrics |

## Design philosophy

Authsome is a set of Go packages you import. You control `main`, the database connection and the HTTP server. There's no sidecar to run.

Bridges are interfaces, so you can swap an external dependency for your own implementation.

Every entity is scoped to an `AppID`, and store lookups take the app (and usually the environment) as an argument.

Authentication methods are plugins, so you opt in to the ones you need. Password, magic links, social login and SSO each register their own routes and strategies when you add them.

Entities use type-prefixed, sortable TypeIDs. Parsing an `ausr_` ID as a session ID fails.

## Quick look

```go
package main

import (
    "context"
    "log"
    "net/http"

    "github.com/xraph/chronicle"
    chstore "github.com/xraph/chronicle/store"
    chmemory "github.com/xraph/chronicle/store/memory"
    "github.com/xraph/forge"
    "github.com/xraph/warden"
    wmemory "github.com/xraph/warden/store/memory"

    "github.com/xraph/authsome"
    "github.com/xraph/authsome/api"
    "github.com/xraph/authsome/bridge/chronicleadapter"
    "github.com/xraph/authsome/middleware"
    "github.com/xraph/authsome/plugins/password"
    "github.com/xraph/authsome/store/memory"
)

func main() {
    ctx := context.Background()

    trail, err := chronicle.New(chronicle.WithStore(chstore.NewAdapter(chmemory.New())))
    if err != nil {
        log.Fatal(err)
    }
    authz, err := warden.NewEngine(warden.WithStore(wmemory.New()))
    if err != nil {
        log.Fatal(err)
    }

    eng, err := authsome.NewEngine(
        authsome.WithStore(memory.New()), // swap for postgres or sqlite in production
        authsome.WithChronicle(chronicleadapter.New(trail)),
        authsome.WithWarden(authz),
        authsome.WithDisableMigrate(),
        authsome.WithPlugin(password.New()),
        authsome.WithBootstrap(authsome.WithBootstrapAppName("Acme")),
    )
    if err != nil {
        log.Fatal(err)
    }
    if err := eng.Start(ctx); err != nil {
        log.Fatal(err)
    }
    defer eng.Stop(ctx)

    router := forge.NewRouter()
    router.Use(middleware.AuthMiddleware(eng.ResolveSessionByToken, eng.ResolveUser, nil))
    if err := api.New(eng).RegisterRoutes(router); err != nil {
        log.Fatal(err)
    }

    log.Printf("listening on :8080, app_id=%s", eng.PlatformAppID())
    log.Fatal(http.ListenAndServe(":8080", router.Handler()))
}
```

Run it with `AUTHSOME_TOKEN_ENCRYPTION_KEY` set to 64 hex characters (`openssl rand -hex 32`). That gives you `POST /v1/signup`, `POST /v1/signin`, `POST /v1/signout`, `POST /v1/refresh`, `GET /v1/me` and the password reset flow.
