---
title: Environments Overview
description: Development, staging and production environments inside one app, with their own users and settings overrides.
---

An environment splits an app's data. Users, sessions and organizations belong to one environment, and each environment can override parts of the app's configuration. `WithBootstrap` creates three for the platform app: Development (the default), Staging and Production.

## The Environment model

```go
import "github.com/xraph/authsome/environment"

type Environment struct {
    ID          id.EnvironmentID `json:"id"`     // aenv_ prefix
    AppID       id.AppID         `json:"app_id"`
    Name        string           `json:"name"`   // "Production"
    Slug        string           `json:"slug"`   // "production"
    Type        Type             `json:"type"`   // development, staging or production
    IsDefault   bool             `json:"is_default"`
    Color       string           `json:"color,omitempty"`
    Description string           `json:"description,omitempty"`
    Settings    *Settings        `json:"settings,omitempty"`
    ClonedFrom  id.EnvironmentID `json:"cloned_from,omitempty"`
    Metadata    Metadata         `json:"metadata,omitempty"`
    CreatedAt   time.Time        `json:"created_at"`
    UpdatedAt   time.Time        `json:"updated_at"`
}
```

| Type | Default color |
|------|---------------|
| `development` | `#22c55e` (green) |
| `staging` | `#eab308` (yellow) |
| `production` | `#ef4444` (red) |

## Environment settings

`Settings` holds per-environment overrides. Every field is optional; nil inherits.

```go
type Settings struct {
    SkipEmailVerification *bool
    AllowTestCredentials  *bool

    TokenTTLSeconds         *int
    RefreshTokenTTLSeconds  *int
    TokenExchangeTTLSeconds *int

    PasswordMinLength *int
    CheckBreached     *bool

    RateLimitEnabled    *bool
    SignInRateLimit     *int
    SignUpRateLimit     *int
    RateLimitWindowSecs *int

    LockoutEnabled     *bool
    LockoutMaxAttempts *int

    WebhookURLOverride string
    OAuthOverrides     map[string]OAuthProviderOverride // per-provider client IDs
}
```

Each type starts from defaults (`environment.DefaultSettingsForType`). Development skips email verification, allows test credentials, sets a 4-character password minimum and turns rate limiting and lockout off. Staging turns rate limiting and lockout on, and production adds the breached-password check.

## Go API

The methods are on the engine:

```go
env := &environment.Environment{
    AppID: appID,
    Name:  "Preview",
    Slug:  "preview",
    Type:  environment.TypeDevelopment,
}
if err := eng.CreateEnvironment(ctx, env); err != nil {
    return err
}
```

`CreateEnvironment` fills in the ID and the type's color when you leave them empty.

| Method | Description |
|--------|-------------|
| `CreateEnvironment(ctx, *Environment)` | Create |
| `GetEnvironment(ctx, envID)` | Get by ID |
| `GetEnvironmentBySlug(ctx, appID, slug)` | Get by slug |
| `GetDefaultEnvironment(ctx, appID)` | The app's default |
| `ListEnvironments(ctx, appID)` | All of an app's environments |
| `UpdateEnvironment(ctx, *Environment)` | Save changes |
| `SetDefaultEnvironment(ctx, appID, envID)` | Make one the default |
| `DeleteEnvironment(ctx, envID)` | Delete. Refused for the default environment |
| `CloneEnvironment(ctx, environment.CloneRequest)` | Copy roles, permissions and webhooks into a new one; see [Cloning](/docs/environments/cloning) |

## HTTP API

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/environments` | List |
| `POST` | `/v1/environments` | Create (`name`, `slug`, `type`, optional `color`, `description`, `settings`, `app_id`) |
| `GET`, `PATCH`, `DELETE` | `/v1/environments/:envId` | Read, update or delete |
| `GET`, `PATCH` | `/v1/environments/:envId/settings` | Read or change the settings overrides |
| `POST` | `/v1/environments/:envId/clone` | Clone |
| `POST` | `/v1/environments/:envId/set-default` | Make it the default |

## Which environment a request uses

The HTTP sign-up and sign-in requests have no environment field: they use the app's default environment. From Go, set `EnvID` on `account.SignUpRequest` or `account.SignInRequest`; an empty one also means the default.

The `middleware` package has an `EnvironmentMiddleware` that resolves an environment from an `X-Environment-ID` header (then an API key prefix, then the default) and puts it on the context, but neither the standalone API nor the Forge extension installs it. Add it to your router yourself if you want it, and read the result with `middleware.EnvIDFrom`, `EnvironmentFrom` or `EnvironmentSettingsFrom`.
