---
title: Environment Cloning
description: Create a new environment from an existing one's settings, roles, permissions and webhooks, without user data.
---

Cloning creates a new environment from an existing one. It copies the settings, the RBAC roles with their permissions, and the webhooks. It never copies users, sessions, organizations, API keys or other user data.

## What gets cloned

| Resource | Cloned | Notes |
|----------|--------|-------|
| Settings | Yes | Merged in order: the new type's defaults, then the source's settings, then `SettingsOverride` |
| Roles and permissions | Yes | New IDs, parents before children, parent links remapped |
| Webhooks | Yes | Same events, active flag and signing secret; the URL can be overridden |
| Users, sessions, organizations, API keys | No | |
| Form configs and branding | No | |

The new environment is never the default, and its color is its type's default color.

## Cloning from Go

```go
import "github.com/xraph/authsome/environment"

result, err := eng.CloneEnvironment(ctx, environment.CloneRequest{
    SourceEnvID: productionEnvID,
    Name:        "Staging",
    Slug:        "staging-2",
    Type:        environment.TypeStaging,
    Description: "Cloned from production",
    SettingsOverride: &environment.Settings{
        LockoutEnabled: ptr(false), // ptr is your own helper
    },
    WebhookURLOverride: "https://staging-hooks.example.com/authsome",
})
if err != nil {
    return err
}

fmt.Printf("cloned %s: %d roles, %d permissions, %d webhooks\n",
    result.Environment.ID, result.RolesCloned, result.PermissionsCloned, result.WebhooksCloned)
```

### CloneRequest fields

| Field | Description |
|-------|-------------|
| `SourceEnvID` | The environment to copy |
| `Name`, `Slug`, `Type`, `Description` | The new environment |
| `SettingsOverride` | Settings applied on top of the merged result; non-nil fields win |
| `WebhookURLOverride` | When set, every cloned webhook points here instead of its original URL |

### CloneResult

`Environment` is the new environment. `RoleIDMap`, `PermissionIDMap` and `WebhookIDMap` map each source ID to its copy, and `RolesCloned`, `PermissionsCloned` and `WebhooksCloned` count them.

The steps aren't wrapped in a transaction. If a role, permission or webhook fails to copy, the new environment and whatever was copied before the failure stay behind, and `CloneEnvironment` returns the error.

Cloned webhooks keep the source webhook's signing secret, so a receiver that verifies production signatures accepts the clone's too. Rotate it with `eng.RotateWebhookSecret(ctx, webhookID)` if the copy shouldn't share it.

## Over HTTP

`POST /v1/environments/:envId/clone`, where `:envId` is the source:

```json
{
  "name": "Staging",
  "slug": "staging-2",
  "type": "staging",
  "description": "Cloned from production",
  "settings": {"lockout_enabled": false},
  "webhook_url_override": "https://staging-hooks.example.com/authsome"
}
```
